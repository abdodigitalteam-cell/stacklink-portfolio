# StackLink Portfolio
موقع بورتفوليو عربي RTL لشركة StackLink باستخدام Next.js وTailwind CSS.

## التشغيل على Windows
1. فك ضغط الملف وافتح المجلد في VS Code.
2. افتح Terminal داخل المجلد وشغّل:

```powershell
npm.cmd install
npm.cmd run dev
```

3. افتح http://localhost:3000

## بناء نسخة الإنتاج
```powershell
npm.cmd run build
npm.cmd run start
```
